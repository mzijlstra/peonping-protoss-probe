# Protoss Probe (StarCraft) — peon-ping sound pack

Original StarCraft (1998) Protoss Probe unit voice lines as a
[CESP](https://openpeon.com/spec) sound pack for [peon-ping](https://github.com/PeonPing/peon-ping).

| Category | Sounds |
|---|---|
| session.start | Comm beep |
| task.acknowledge | Affirmative, It shall be done, Acknowledged, As you wish |
| task.complete | Resource delivered |
| task.progress | Warp in progress |
| task.error | Unable to comply, Not possible |
| input.required | Awaiting orders, Your command?, Standing by |
| resource.limit | Insufficient resources |
| user.spam | Impatient probe, Enough! |
| session.end | Probe terminated |

## Install

```
peon packs install protoss_probe
peon packs use protoss_probe
```

Or from a local clone: `peon packs install-local .`
